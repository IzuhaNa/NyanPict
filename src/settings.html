NyanPict SPA - Pengaturan API

⚙️ Pengaturan Akun & API

Konfigurasikan akun dan API Booru untuk NyanPict.

Mode Keamanan Konten (NSFW)

Aktifkan untuk mengizinkan pencarian konten eksplisit.

⚠️ Pengaturan ini merupakan filter pencarian, bukan verifikasi usia.

DNS Override

Ganti DNS resolver untuk mengatasi blokir situs oleh Wi-Fi/ISP. Pilih DNS publik terbuka (Google, Cloudflare, atau OpenDNS).

⚠️ Butuh admin/elevated untuk edit file hosts. Aplikasi harus berjalan sebagai admin untuk fitur ini.

Gambar per Halaman

Pilih jumlah gambar yang akan dimuat pada setiap page load. Lebih banyak gambar = loading lambat tapi hemat scrolling.

Kualitas Gambar

Pilih resolusi thumbnail yang digunakan.

Kredensial API Booru

Masukkan User ID, Username, dan API Key yang sesuai dengan akun masing-masing.

API Key dapat dikosongkan apabila tidak menggunakan autentikasi API.

Gunakan username dan API Key dari akun Danbooru.

🔐 Informasi keamanan: Kredensial disimpan di localStorage aplikasi. Penyimpanan ini bukan brankas rahasia dan kredensial masih dapat diakses melalui DevTools atau file profil aplikasi. Jangan membagikan folder data aplikasi kepada orang lain.
